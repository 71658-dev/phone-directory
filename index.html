使用教學
打幾個字，一次縮到剩幾個人
多個詞用空格隔開，只留下同時符合全部詞的人員。
打 醫政 專責 ➜ 只剩醫政科裡承辦專責業務的人。
打不準也找得到
口語、俗稱、縮寫都可以——系統會自動幫你對照到名冊上實際的寫法，命中的字會用黃底標出來；用到同義詞時，結果上方也會註明「同時搜尋了…」。

科室篩選、★ 常用
點搜尋框下方的科室按鈕，只看該科室的人。
點人員列右側的 ★ 釘選常用聯絡人，之後點「★ 常用」隨時叫出來，釘選的人一律排最上面，打開這頁時也會直接列出來。
快捷鍵
/ 直接跳到搜尋框開始打字。 Esc 清空搜尋，或關掉目前的視窗。
複製分機・最近查過
點一下藍色的分機號碼就會複製起來；複製過的人會記在「最近」，下次不用再搜尋。搜尋「傳真」、「專線」或科室名稱，也會列出各科的專線與傳真號碼。
新增
1按右上角「＋ 新增分機」（手機版是「＋」）。
2填姓名和分機（必填），其餘欄位盡量填，方便同事之後搜尋到。
3按「儲存」，馬上生效。
編輯
按人員列右側的鉛筆圖示（手機版直接點那一列），改完想改的欄位，按「儲存」即可。
刪除
先打開編輯視窗，按最下方的「刪除這筆資料」，系統會再問一次才刪，不怕手滑按到。
資料放在哪裡
新增、編輯、刪除都只存在這台電腦的瀏覽器裡，不會上傳到任何伺服器。
第一次使用
畫面出現「還沒有分機名冊」時，按「匯入名冊檔案」，選取局內的 Excel 分機一覽表 (.xlsx)，或同事匯出的 phoneData.csv 就能開始用。
換成最新名冊
拿到新版 Excel 分機表時，按右上角「更多」→「匯入名冊」直接選 .xlsx 檔。系統會先列出新增、刪除、變更的人，確認後按「套用更新」才會寫入；大家手動填的業務內容都會保留。
Excel 開著的時候，資料夾裡會多一個檔名開頭是 ~$ 的暫存檔，那個不是名冊，請選沒有 ~$ 的檔案。
匯入錯了怎麼辦
每次更新前會自動保留一份舊資料，在「更多」選單按「復原匯入」就能回到匯入前的狀態。
補上新同事的業務
新加入名冊的人業務欄位是空的。點科室列最後的「待補業務」，就能列出所有還沒填業務的人，逐一點鉛筆補上。
備份你改過的資料
手動補充或修改過資料後，按右上角「更多」→「匯出 CSV」存一份，檔名會自動加上日期，避免清瀏覽器紀錄時整批遺失。
進階：放在共用網站上（管理員）
把這個資料夾放到局內網站，並在同一層放一份 phoneData.csv，同事打開網頁時就會自動載入；之後替換這個 CSV，大家的畫面會出現「名冊有更新」提示，按一下就能比對更新。直接從電腦開啟檔案時瀏覽器不允許自動讀取，只能手動匯入。
這是什麼
就是「搜尋」頁籤提到的口語對照表——打針 ➜ 疫苗 這類寫法。按右上角「更多」→「詞庫管理」就能自己新增或調整，不用等改版。
新增對照詞
1按「＋ 新增詞彙」。
2填口語 / 民間俗稱（例如「月子中心」），以及對應名冊業務標籤，多個用逗號隔開（例如「產家, 產後護理」）。
3按「儲存詞彙」，搜尋馬上就找得到。
編輯・刪除・找詞
按列表右側的鉛筆圖示修改，或垃圾桶圖示刪除（會再問一次才刪）。詞庫上方的搜尋框可以用口語或業務關鍵字快速找到已建的對照詞。
匯出・匯入・清空詞庫
「匯出」存成 JSON 檔備份，方便帶到別台電腦用；「匯入」會把 JSON 內的對照詞合併進現有詞庫；「清空詞庫」會刪除所有對照詞，詞庫預設是空的。
資料放在哪裡
自訂的對照詞一樣只存在這台電腦的瀏覽器裡，不會上傳到任何伺服器；換電腦要用的話記得先匯出再到新電腦匯入。
