# 分機查詢 phone-directory

一個打開就能用的分機名冊查詢工具。整個程式只有一個 HTML 檔，不用安裝、不用網路、不用伺服器，雙擊就能開。

**線上使用：<https://71658-dev.github.io/phone-directory/>**

## 特色

- **一個檔案就能用**：`分機查詢.html` 已經把所有程式和樣式打包在裡面，複製到隨身碟或寄給同事都能直接開。
- **打幾個字就縮到剩幾個人**：可以用姓名、分機、業務、科室搜尋。多個詞用空格隔開，只留下同時符合全部詞的人，例如打 `資訊 帳號`。
- **縮寫、口語也找得到**：縮寫會自動比對，例如打「資安」會找到「資訊安全」。口語或俗稱可以自己建立同義詞對照，例如設定「報帳」對應「請款」後，打「報帳」也會找到請款的承辦人。詞庫預設是空的，在「更多」→「詞庫管理」新增，或匯入別人匯出的 JSON 詞庫檔。
- **常用與最近**：按 ★ 釘選常用聯絡人；點分機號碼就會複製，複製過的人會記在「最近」。
- **科室專線與傳真**：搜尋「傳真」、「專線」或科室名稱，會列出各科的號碼。
- **更新名冊不怕弄亂**：匯入新版 Excel 時，會先列出新增、刪除、變更的人，確認後才套用；大家手動補的業務內容會保留。匯入錯了可以「復原匯入」。
- **鍵盤快速鍵**：`/` 跳到搜尋框，`Esc` 清空搜尋或關閉視窗。

## 怎麼用

1. 用 Chrome 或 Edge 打開程式，以下兩種方式擇一：
   - **線上版**：直接開 <https://71658-dev.github.io/phone-directory/>，不用下載。
   - **離線版**：下載 [`分機查詢.html`](分機查詢.html)，雙擊打開，沒有網路也能用。
2. 第一次打開會顯示「還沒有分機名冊」，按「匯入名冊檔案」，選取 Excel 分機一覽表（`.xlsx`）或之前匯出的 `phoneData.csv`。
3. 開始搜尋。

> 線上版和離線版的資料是分開存的。名冊匯入到哪一個，就只在那一個看得到。

> Excel 開著的時候，資料夾裡會多一個檔名開頭是 `~$` 的暫存檔，那不是名冊，請選另一個檔案。

### 範例檔

[`examples/`](examples/) 資料夾有兩個範例檔，內容都是虛構的，可以先匯入試用，或照著格式整理自己的資料。

**[`phoneData.csv`](examples/phoneData.csv)：分機名冊**

第一列是欄位名稱，其中 `ext` 和 `name` 必填，其他可以留空，欄位順序不限：

| 欄位 | 內容 | 例子 |
|---|---|---|
| `ext` | 分機 | `405` |
| `name` | 姓名 | `鄭雅雯` |
| `id` | 工號（更新名冊時用來比對同一個人） | `00012` |
| `note` | 備註 | `週三下午不在` |
| `task` | 業務內容，多項用頓號隔開 | `帳號申請、電子郵件` |
| `dept` | 部門 | `資訊部` |
| `role` | 職稱 | `經理` |

用 Excel 編輯時，請「另存新檔」成 **CSV UTF-8（逗號分隔）**，不然中文可能變成亂碼。匯入：「更多」→「匯入名冊」。

**[`synonyms.json`](examples/synonyms.json)：同義詞庫**

左邊是使用者可能會打的口語或俗稱，右邊是名冊上實際的寫法（可以有好幾個）：

```json
{
  "報帳": ["請款", "核銷"],
  "電腦壞了": ["報修"]
}
```

匯入：「更多」→「詞庫管理」→「匯入」。匯入的詞會合併進現有詞庫，不會覆蓋原本的詞。

### 新增、修改、刪除

- **新增**：按右上角「＋ 新增分機」，填姓名和分機（必填），按「儲存」。
- **修改**：按人員列右側的鉛筆圖示（手機版直接點那一列）。
- **刪除**：在編輯視窗最下方按「刪除這筆資料」，系統會再確認一次。
- **補新同事的業務**：點科室列最後的「待補業務」，會列出還沒填業務的人。

### 備份

改過資料後，按右上角「更多」→「匯出 CSV」存一份，檔名會自動加上日期。清除瀏覽器紀錄時資料會一起不見，所以記得定期匯出。

## 資料放在哪裡

**名冊只存在你自己電腦的瀏覽器裡**（localStorage），不會上傳到任何伺服器，用線上版也一樣。這個 repo 裡也沒有任何真實名冊，程式裡只有 16 筆虛構的示範資料。

也因為這樣，每台電腦、每個瀏覽器的資料是分開的，換電腦要重新匯入或用 CSV 搬過去。

## 放在共用網站上（給管理員）

把整個資料夾放到內部網站，並在同一層放一份 `phoneData.csv`，同事打開網頁時就會自動載入。之後只要替換這個 CSV，大家的畫面就會出現「名冊有更新」的提示，按一下就能比對更新。

> 直接從電腦雙擊開啟（`file://`）時，瀏覽器不允許自動讀取旁邊的檔案，只能手動匯入。

> ⚠️ **不要把 `phoneData.csv` 放進這個 repo。** 線上版是公開網站，放進來的名冊任何人都能下載。要用自動載入功能，請放在只有內部網路連得到的網站。

## 給開發者

### 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 主程式（畫面與互動邏輯） |
| `phone-search.js` | 搜尋、同義詞、CSV/Excel 解析、示範資料 |
| `ios-kit.css` | 畫面樣式 |
| `support.js` | 執行環境，負責載入 React 並啟動畫面 |
| `_ds/` | 介面元件套件（Claude Design 設計系統，**不包含在 repo 內**） |
| `vendor/` | React、ReactDOM 等第三方程式庫（本機副本，離線可用） |
| `favicon.svg` | 網頁小圖示 |
| `build-single.ps1` | 打包腳本，把上面全部合併成 `分機查詢.html` |
| `分機查詢.html` | 打包好的單一檔案版本 |

### 修改後重新打包

改完原始檔後，在資料夾裡執行：

```powershell
.\build-single.ps1
```

腳本只會讀原始檔、寫出 `分機查詢.html`，不會改動其他檔案。打包完如果還有外部檔案參照，會顯示警告。

> 打包腳本需要 `_ds/ios-27-ui-kit-*/_ds_bundle.js`。這是 Claude Design 的設計系統檔案，沒有放進 repo，所以從 GitHub 下載的版本不能直接重新打包。開 `index.html` 不受影響，只是瀏覽器主控台會出現一個找不到 `_ds_bundle.js` 的 404 訊息。

> 開發時直接開 `index.html` 也能測試，但要從本機網站（例如 `npx serve`）開啟，用 `file://` 開會被瀏覽器的安全限制擋住部分功能。
